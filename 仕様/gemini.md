# ウェブサイト実装仕様書：和地たなか歯科（クローン制作）

## 1. 基本要件（プロジェクト概要）
* **ターゲット端末**: レスポンシブWebデザイン（Mobile First推奨）
    * ブレイクポイント: `sp: ~767px`, `tab: 768px ~ 1023px`, `pc: 1024px ~`
* **対応ブラウザ**: Google Chrome, Safari, Firefox, Edge（各最新版）
* **パフォーマンス目標**: Lighthouseスコアにて、Performance 85以上、Accessibility 95以上、SEO 90以上。
* **技術スタック（推奨）**:
    * Markup: HTML5 (セマンティックタグを適切に使用)
    * Styling: CSS3 / Sass (SCSS記法) または Tailwind CSS
    * Scripting: Vanilla JavaScript (ES6+)
    * Libraries: Swiper.js（スライダー用）, GSAP または Intersection Observer API（スクロールアニメーション用）

## 2. サイトマップ・ディレクトリ構造
基本的には、ユーザーのスクロール体験を重視した**縦長（ランディングページ型）＋下層・機能ページ**の構成を想定します。

1.  `index.html` (トップページ)
    * FV（ファーストビュー）
    * お知らせ（News）
    * 当院の特徴（Features）
    * 診療案内（Services）
    * 院長挨拶（Greeting）
    * アクセス・医院情報（Access/Info）
    * お問い合わせフォーム（Contact）
2.  外部遷移
    * Web予約システム / Web問診システム
    * Instagramへのリンク

## 3. デザインシステム（共通定義）

### 3.1. タイポグラフィ（フォント）
医療機関としての「信頼感」と「優しさ」を両立させるため、ゴシック体と明朝体を使い分けます。
* **ベースフォント (本文)**: `Noto Sans JP` または `Zen Kaku Gothic New` (視認性重視)
* **見出しフォント (キャッチコピー等)**: `Noto Serif JP` または `Shippori Mincho` (情緒感・品格)
* **基本フォントサイズ**: PC 16px / SP 14px (remで管理)

### 3.2. カラースキーム（CSS変数設計）
サイトの雰囲気を統一するため、以下のようなCSS変数を定義して運用します（実際の色味は元のサイトをスポイトツール等で抽出して設定してください）。

```css
:root {
  --color-primary: #xxxxxx; /* メインカラー（例：温かみのあるオレンジや清潔なブルー） */
  --color-secondary: #xxxxxx; /* アクセントカラー */
  --color-text-main: #333333; /* 本文テキスト（真っ黒を避け、柔らかく） */
  --color-text-muted: #666666; /* サブテキスト */
  --color-bg-base: #FAFAFA; /* 全体の背景色（わずかにグレー/クリームがかった白） */
  --color-bg-section: #FFFFFF; /* セクション背景色 */
  --color-border: #E0E0E0; /* 境界線 */
}
```

### 3.3. 共通コンポーネント（UI要素）
* **ボタン (Button)**:
    * **予約ボタン (Primary)**: 最も目立つ配色。ホバー時にふんわりと浮き上がる（`box-shadow`）または色が変わる（`transition: 0.3s ease`）アニメーション。
    * **通常ボタン (Secondary)**: 枠線のみ（アウトラインボタン）、ホバーで背景色塗りつぶし。
* **見出し (Heading)**:
    * セクションタイトル（h2）は、英語表記（例：FEATURES）と日本語表記（例：当院の特徴）を重ねる、または添えるデザインで統一。

## 4. セクション別 実装・挙動仕様

### ① Header（ヘッダー）＆ナビゲーション
* **PC挙動**: 画面上部に固定（Sticky）。スクロールダウンで少し縮小（高さを抑える）し、コンテンツの邪魔をしないようにする。
* **SP挙動**: ハンバーガーメニューを実装。開閉時はフェードイン、または右からスライドインするドロワーメニュー。
* **必須要素**: ロゴ（左）、グローバルナビ（中央〜右）、「Web予約」のCV（コンバージョン）ボタン（右端・常時表示）。

### ② First View（ファーストビュー / ヒーローセクション）
* **構造**: 画面いっぱいのサイズ（`height: 100vh` または `svh`）。
* **画像/動画**: 「ここから笑顔がうまれる。」というコピーの背景で、院内や人物の画像がゆっくりとクロスフェードするスライダー（Swiper.jsの`effect: fade`等を使用）。
* **アニメーション**: ページロード時、キャッチコピーがフワッと浮かび上がる（`opacity: 0` から `1` へ、`transform: translateY` を併用）。

### ③ 当院の特徴（Features） - 6つのポイント
* **レイアウト**: PCではカード型の2列または3列グリッド（`display: grid`）。SPでは1列。
* **アニメーション**: スクロールして要素が画面内に入った瞬間（Intersection Observerを使用）、各カードが下から順番にフェードインする（Staggered Animation）。
* **コンテンツ**: 番号（1〜6）、タイトル、説明文、イメージ画像を内包。

### ④ 診療案内（Services）
* **レイアウト**: 各診療項目（一般歯科、小児歯科、予防歯科など）を、バッジ（タグ）状のUI、またはアイコン付きのリストで網羅的に表示。
* **UIの工夫**: 項目数が多いため、カードを並べるか、ホバー時に詳細がツールチップやアコーディオンで展開される仕様にするとスッキリします。

### ⑤ アクセス・医院情報（Access / Info）
* **テーブル実装**: 診療受付時間の表（平日・土曜・休診日）は、HTMLの`<table>`タグを用いてセマンティックにマークアップ。SPでは横幅がはみ出ないよう調整。
* **マップ**: Google Mapsのiframe埋め込み、またはスタティック画像＋Google Mapsへの外部リンク。
* **交通手段**: 車、バス、電車、高速道路の4パターンの案内を、タブ切り替え（Tab）またはアイコンリストで見やすく整理。

### ⑥ お問い合わせフォーム（Contact）
* **バリデーション（入力チェック）**:
    * 「お名前」「メールアドレス」「お問い合わせ内容」は必須（`required`属性）。
    * メールアドレスの形式チェック（HTML5の`type="email"`またはJSでの正規表現チェック）。
* **UI/UX**: 
    * 入力中のフィールドの枠線をハイライト（`:focus`擬似クラス）。
    * 「プライバシーポリシーに同意する」のチェックボックスにチェックが入らないと「送信」ボタンが押せない仕様（JSで制御、または`:checked`を使用）。

### ⑦ Footer（フッター）
* 各種施設基準（加算に関する記述）をリスト化して配置。文字サイズは少し落とし（`--color-text-muted`等を使用）、誠実かつ目立ちすぎない設計に。
* プライバシーポリシーへのリンク、コピライト（`&copy;`）を配置。
